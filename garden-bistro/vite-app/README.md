# Replacement client — under construction

This Vite/React/TypeScript client is an **incomplete migration**, not the production website. It is not configured in the root Netlify build. The existing Next.js app and database remain in use. The homepage and staff sign-in are the only implemented routes. The sign-in uses Supabase Auth when a project URL and publishable/anon key are provided; no role-based admin authorization, operational dashboard or database workflows exist in this client yet. A signed-in session alone never grants administrative capabilities here.

Run `npm ci`, copy `.env.example` to `.env.local`, supply the public Supabase URL and publishable/anon key, then `npm run dev`. Do not put a service-role key or R2 credentials in Vite environment variables. The client is deliberately noindex and is not ready for deployment or for receiving business orders. Before cutover implement and verify server-side authorization/RLS, migration of data and media to R2, server-side business operations, localization, remaining routes and end-to-end security tests. The existing `../public` assets are used temporarily by Vite for development and build; this is not the required R2 media architecture.
